## How validators agree

The leader asks its model and returns four strings: verdict, tier, conditions and reason. Each validator asks its own model the same prompt and agrees only when its own **verdict and tier id** match the leader's. The conditions and the reason are stored from the leader's answer for display and are never compared.

An answer that cannot be read (not JSON, a label outside the four, or PAID without a tier of this license) is retried once, then fails the round. It never becomes a verdict.
