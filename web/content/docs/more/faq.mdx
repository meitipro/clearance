## FAQ

### Who decides?

Several GenLayer validators, each reading the same license against the same use with their own model. An answer
stands only when they agree on the verdict and, for PAID, on the tier. The creator keeps the last word on every
UNCLEAR request.

### Can the creator change the answer later?

Not an answer that already stands. A creator can answer an UNCLEAR request once and grant an exception to a DENIED
one once. They can amend the license, which changes the answer to the next request like it; receipts already issued
keep their version.

### Why did I get UNCLEAR?

The license did not say enough to decide, or the use was too vague. Say where, how many, commercial or not, and for
how long, or wait for the creator's answer in their studio.

### What does a request cost?

A network fee deposit on Studio Next, estimated by the SDK. Most of it is refunded when the transaction finalizes.
Buying a tier costs its price, which goes to the creator.

### Is my wallet needed to read?

No. Works, licenses, answers and receipts read without a wallet. One is needed only to publish, ask, buy, answer or
withdraw.

### Which network?

GenLayer Studio Next, chain 61997, RPC `https://studio-next.genlayer.com/api`. See
[Addresses and network](/docs/reference/addresses).

### Is there an ask fee against spam?

No; see [Limitations](/docs/more/limitations).
